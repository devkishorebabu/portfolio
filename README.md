# Poluru Kishore Babu — Portfolio

A personal portfolio website built with React, showcasing my experience as a DevOps Engineer.

**Live:** [https://devkishorebabu.github.io/portfolio](https://devkishorebabu.github.io/portfolio)

## Features

- Dark theme with cyan accents
- Scroll-triggered animations with staggered reveals
- Responsive design for all screen sizes
- Smooth scrolling navigation
- Interactive hover effects with glowing borders and gradients
- Typing animation on hero section

## Tech Stack

- **React 19** — UI framework
- **React Scroll** — smooth section navigation
- **React Icons** — icon library
- **CSS3** — custom animations, transitions, and gradients
- **GitHub Pages** — hosting

## Sections

- **Hero** — intro with social links
- **About** — summary and highlight cards
- **Skills** — categorized technical skills
- **Experience** — professional timeline
- **Projects** — featured project cards
- **Education** — academic background
- **Contact** — email, phone, and social links

## Getting Started

```bash
# Install dependencies
npm install

# Run locally
npm start

# Build for production
npm run build

# Deploy to GitHub Pages
npm run deploy
```
